# LexLab —— 《编译原理》实验一：词法分析

广州大学《编译原理》探索性实验（一）。用 C# / .NET 9 / WinForms 实现的词法分析实验系统，
在完成基础要求之外，还实现了指导书中的两项探索性实验。

## 实验内容

| 部分 | 说明 |
| --- | --- |
| 基础实验 | 对 C 语言子集源程序做词法分析，输出 `(种别码, 单词符号)` 二元组序列，并给出单词种类、常量值、行号与列号；能检测非法字符、非法数值、未结束注释等错误，一次运行报出全部词法错误 |
| 探索实验（一） | 正规式 → ε-NFA → DFA → 最简 DFA 的自动构造：Thompson 构造法、子集法确定化、分割法最简化，并自动绘制状态转换图 |
| 探索实验（二） | 源代码图片 OCR 识别后再做词法分析：图像预处理（自动反色、放大、二值化）+ Tesseract 识别，识别结果可手工修正后再分析 |
| 扩展设计 | 单词符号与种别码全部外置在 `lexer.config.json`，新增关键字/运算符只需改配置，无需重新编译 |

## 构建与运行

环境要求：Windows 10/11 + [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

```powershell
cd src/LexLab
dotnet run
```

发布为单文件 exe（所有依赖、OCR 引擎与语言数据都打包进一个文件，目标机无需安装任何环境）：

```powershell
cd src/LexLab
dotnet publish -c Release
# 产物：bin/Release/net9.0-windows/win-x64/publish/LexLab.exe
```

## 使用说明

- 界面分三个标签页：① 词法分析　② 正规式 → NFA → DFA → 最简 DFA　③ 图片识别并分析。
- “内置示例”下拉框可载入指导书样例、综合示例、错误示例等；也可自行编辑或粘贴源程序。
- 种别码配置：程序首次运行会在 exe 同目录生成 `lexer.config.json`，可直接编辑该文件扩展关键字与运算符。
